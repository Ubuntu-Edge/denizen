Denizen AI Engine — Open Source Manual

Denizen AI Engine is a 100% open-source, privacy-first on-device AI orchestrator for Flutter apps, released under the permissive MIT License. Maintained by the Ubuntu Edge team, Denizen enables mobile and desktop applications to run local LLMs, vector RAG search, structured tool calling, and voice sessions with zero cloud API fees and complete offline privacy.

100% Open-Source Guarantee: All client-side runtime engines (local GGUF inference via llama.cpp, local vector storage via sqlite-vec, TFLite embeddings, GBNF grammar compilers, and Whisper voice loops) are completely free, open-source, and un-throttled.

Installation & Package Setup

Private Developer Beta Access: Denizen AI SDK is currently in controlled private beta testing. Contact the Ubuntu Edge team to obtain a read-only BETA_ACCESS_TOKEN to enable flutter pub get.

Add denizen_ai to your Flutter project's pubspec.yaml file using your Beta Access Token:

pubspec.yaml 
dependencies:
  flutter:
    sdk: flutter

  denizen_ai:
    git:
      url: https://@github.com/Ubuntu-Edge/denizen-ai-sdk.git
      ref: main

  path_provider: ^2.1.1
  connectivity_plus: ^6.1.0

Execute in your terminal:

terminal 
flutter pub get

Engine Quickstart

Initialize the DenizenAI engine, load a local model, and execute streaming inference:

main.dart 
import 'package:flutter/material.dart';
import 'package:path_provider/path_provider.dart';
import 'package:denizen_ai/denizen_ai.dart';
import 'package:path/path.dart' as p;

void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  final docsDir = await getApplicationDocumentsDirectory();
  final modelPath = p.join(docsDir.path, 'models', 'qwen2.5-0.5b-instruct-q4_k_m.gguf');

  final denizen = DenizenAI();
  
  // Download model if not cached
  await denizen.models.downloadModel(
    url: 'https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/resolve/main/qwen2.5-0.5b-instruct-q4_k_m.gguf',
    modelId: 'qwen2.5-0.5b-q4',
    savePath: modelPath,
  );

  // Load GGUF model into native llama.cpp memory
  await denizen.models.loadFromFile(modelPath);

  // Create stateful conversation session
  final session = denizen.createSession(systemPrompt: 'You are an offline assistant.');

  // Stream tokens in real-time
  session.streamChat('Explain how on-device AI works in 2 sentences.').listen((chunk) {
    print(chunk); // Streams generated tokens to UI
  });
}

Model Lifecycle Manager (`DenizenModelManager`)

The DenizenModelManager handles downloading GGUF models, local file importing, memory loading into native llama.cpp, and automatic Least Recently Used (LRU) storage eviction to keep device disk space safe.

Complete 5-Step Model Lifecycle Flow

model_download_flow.dart 
import 'package:denizen_ai/denizen_ai.dart';

// 1. Check if model is already downloaded on device
final isDownloaded = await DenizenAI().models.isDownloaded('qwen2.5-1.5b-instruct-q4');

if (!isDownloaded) {
  print('Model not on device. Starting download with progress...');
}

// 2. Download (if missing) & Load into RAM in a single call
try {
  await DenizenAI().models.load(
    'qwen2.5-1.5b-instruct-q4',
    requireWifi: true, // Block download on Cellular data if true
    onProgress: (progress) {
      print('Stage: ${progress.stage}');
      print('Progress: ${(progress.progress * 100).toStringAsFixed(1)}%');
      print('Downloaded: ${progress.bytesDownloadedMB} MB');
    },
  );
  print('✅ Model loaded into llama.cpp memory and ready for inference!');
} on StorageQuotaException catch (e) {
  print('❌ Storage Full: ${e.message}');
} on NetworkException catch (e) {
  print('❌ WiFi required for download.');
}

// Note: Denizen automatically detects pre-pushed GGUF files in 
// /sdcard/Download/ or /data/local/tmp/ for offline enterprise deployment!

Deep Dive: Prompting & Token Streaming (`DenizenSession`)

Conversations in Denizen are managed via DenizenSession instances. A session maintains chat history, enforces system prompts, and automatically handles sliding context window eviction when chat history threatens to exceed the model's native context limit.

Sliding Context Window Eviction

When a session exceeds the loaded context limit (e.g. 2048 or 4096 tokens), Denizen automatically resolves loadedContextSize and evicts older conversation turns while keeping the original systemPrompt intact.

Generation Parameters

Parameter Default Description
maxTokens 512 Maximum tokens to generate per output response turn.
temperature 0.8 Controls randomness. Lower values (0.2) make responses deterministic; higher values (1.0) increase creativity.
topP 0.95 Nucleus sampling threshold. Considers tokens with topP cumulative probability.
topK 40 Top-K sampling limit. Restricts candidate tokens to top K highest probabilities.
repeatPenalty 1.1 Penalizes repeated word loops in long generation outputs.

Synchronous Chat vs Token Streaming Example

prompting_demo.dart 
final denizen = DenizenAI();
final session = denizen.createSession(
  systemPrompt: 'You are an expert Flutter developer.',
  maxTokens: 1024,
);

// Method 1: Synchronous Response (Awaits complete generation)
final reply = await session.chat('How do I build a custom RenderObject?');
print(reply);

// Method 2: Token Streaming (Real-time UI updates)
final stream = session.streamChat(
  'What is the difference between Stateless and Stateful widgets?',
  temperature: 0.7,
);

stream.listen(
  (token) => setState(() => currentOutput += token),
  onDone: () => print('Streaming completed.'),
);

Offline Vector RAG Engine

Denizen includes a native offline RAG (Retrieval-Augmented Generation) pipeline powering vector similarity search using sqlite-vec and local 384-dimensional TFLite embeddings. No external servers or API keys are required.

Step-by-Step Developer Integration

rag_demo.dart 
import 'dart:io';
import 'package:denizen_ai/denizen_ai.dart';

// 1. Initialize Local Embedding Provider & Vector Storage Service
final embeddingProvider = TFLiteEmbeddingProvider();
await embeddingProvider.initialize();

final storageService = VectorStorageService();
await storageService.initialize(); // Automatically loads sqlite-vec FFI

// 2. Ingest Local Document (.pdf, .txt, .md, .csv)
final ingestionService = DocumentIngestionService(embeddingProvider, storageService);

// Option A: Ingest local file directly (handles PDF text extraction automatically)
await ingestionService.ingestFile(
  1, // Document ID
  File('/path/to/clinical_manual.pdf'),
  chunkSizeWords: 200,
  overlapWords: 30,
);

// Option B: Ingest raw text string
await ingestionService.ingestText(
  2,
  "Emergency Protocol: In case of acute fever over 38.5°C, administer paracetamol...",
);

// 3. Create RAG-Enabled Session & Stream Answer
final ragSession = DenizenAI().createRagSession(
  embeddingProvider: embeddingProvider,
  storageService: storageService,
  baseSystemPrompt: 'You are an offline clinical assistant. Use retrieved context to answer accurately.',
);

// Context retrieval from sqlite-vec happens automatically under the hood!
final stream = ragSession.streamChat('What is the protocol for acute fever?');
stream.listen((token) {
  print(token); // Real-time token streaming to UI
});

// Note: You can also load pre-built domain knowledge databases from Flutter assets:
// await DenizenAI().loadBundledKnowledge('assets/medical_rag.db');

Structured Tool Calling (GBNF Context Grammars)

Denizen uses pre-compiled GBNF context grammars to constrain local GGUF model outputs, guaranteeing 100% valid JSON function calling without syntax errors.

tool_demo.dart 
// Define Custom Executable Tool
class GetLocationTool extends DenizenTool {
  GetLocationTool() : super(
    name: 'get_user_location',
    description: 'Returns current device latitude and longitude.',
    parametersSchema: {'type': 'object', 'properties': {}},
  );

  @override
  Future> execute(Map arguments) async {
    return {'lat': -1.286389, 'lng': 36.817223}; // Nairobi coordinates
  }
}

// Register & Execute via Tool Session
final registry = DenizenToolRegistry();
registry.registerTool(GetLocationTool());

final toolSession = DenizenToolSession(denizen.engine, registry);
final result = await toolSession.chat('Where am I currently located?');
print(result);

Deep Dive: Conversational Voice Loop (`DenizenVoiceSession`)

The DenizenVoiceSession implements a real-time, hands-free voice consultation loop operating 100% offline. It pairs Whisper Speech-to-Text (STT) with Flutter's native Text-to-Speech (TTS) audio engine.

Voice Pipeline Architecture

``` Microphone Audio ──▶ Offline Whisper STT ──▶ Denizen Local LLM ──▶ Native TTS ──▶ Speaker Audio ```

Voice Consultation Code Example

voice_demo.dart 
import 'package:denizen_ai/denizen_ai.dart';

final denizen = DenizenAI();

// Create Voice Session
final voiceSession = DenizenVoiceSession();

// Start Hands-Free Speech Loop
await voiceSession.startListening(
  onSpeechRecognized: (userText) {
    print('User Spoke: $userText');
  },
  onResponseGenerated: (aiReply) {
    print('AI Spoke Back: $aiReply');
  },
  systemPrompt: 'You are a friendly voice tutor.',
);

// Stop Voice Session
await voiceSession.stopListening();

Ubuntu Edge Platform Cloud Extensions

Connect your open-source SDK instances to the private Ubuntu Edge Platform for cloud fallback, managed delta OTA model updates, and multi-device vector sync.

ubuntu_edge_config.dart 
// Unlock Ubuntu Edge Cloud Platform via single configuration hook
await denizen.connectUbuntuEdge(
  apiKey: 'ue_live_secret_key_xxx',
  options: UbuntuEdgeOptions(
    enableSmartCloudFallback: true, // Elevates heavy queries to 70B cloud models
    enableVectorCloudSync: true,    // Multi-device cross-platform RAG sync
    enableOtaModelUpdates: true,    // 80% compressed Delta OTA model patches
    multilingualGateway: true,      // Unlocks 50+ Pan-African & Global languages
  ),
);
Zero Data Retention Guarantee: Ubuntu Edge Cloud Fallback operates under strict Zero Data Retention (ZDR) rules. Prompts are processed strictly in GPU RAM and immediately purged upon response completion.
